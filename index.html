Privacy policy — personal CTC automation

Effective date: 8 October 2026

This application is a personal document-processing tool operated by the owner of hereishong@gmail.com. It prepares certified true copies and signature-box documents for the owner's review.

Google data accessed

The application reads Gmail profile information, searches incoming messages from its configured allowed senders, reads those messages and their attachments, and checks existing sent replies to prevent duplicates. It sends a reply only after the owner explicitly approves the exact prepared batch. It uses Google Drive to store files created by this application, including originals, the owner's saved signature, generated PDFs, processing records and approval evidence.

Processing and storage

Document processing runs in a private GitHub repository through GitHub Actions. Google authorization credentials are held in encrypted repository secrets. The signature and authoritative document bundles are stored in private Google Drive storage. PDF previews and outputs may also be stored as private GitHub Actions artifacts for seven days. The application does not intentionally make identity documents or signatures public.

Records and Drive files remain until the owner deletes them. The owner can remove GitHub artifacts and Drive files and revoke the application's Google account access. Stored files should also be deleted when no longer needed.

Use and sharing

Google data is used only to perform the requested CTC workflow, maintain approval records and prevent duplicate replies. It is not sold or used for advertising. Processing uses Google and GitHub infrastructure. Approved completed documents are shared only with the verified original sender of the request, with no Cc or Bcc.

This application uses deterministic document-processing code; it does not send document contents to an AI model as part of its GitHub processing workflow. The owner's separate use of assistants to review documents is outside this application.

Control and contact

The owner can disable scheduled processing, delete stored files, revoke Google authorization, and withhold approval for any document. Questions about this application or deletion requests can be sent to hereishong@gmail.com.
